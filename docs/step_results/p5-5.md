# P5-5 — Workflow 캔버스, 읽기 (의존 하나를 들인 자리)

**Workflow 그래프가 화면에 그려집니다.** 끌기·연결·저장은 아직 없습니다(P5-6). 이 단위의 무게는 그림이 아니라 **새 시각 의존을 들이는 절차**였습니다 — spec 0007 **R-10** 이 "DESIGN.md 가 먼저 적는다" 를 요구하고, 그 결정은 **H-1** 로 사람에게 가 있었습니다. H-1 이 닫힌 뒤에야 이 단위가 섰습니다.

## 무엇이 생겼는가

- **화면 하나** — `app/workflows/[id]/page.tsx`. 서버 컴포넌트가 `getWorkflow` 로 **현재 Version 의 그래프**를 읽고, 캔버스는 `"use client"` 컴포넌트(`WorkflowCanvas.tsx`)가 그립니다. `/workflows` 목록의 정의 표 이름 칸이 여기로 옵니다.
- **SDK 함수 하나** — `getWorkflow(workflowId)`. api 에는 `GET /workflows/{id}` 가 Phase 4 부터 있었는데 **SDK 에 함수가 없었습니다**(plan 개정 3). `getWorkflowVersion` 은 **만들지 않았습니다** — 버전을 골라 보는 화면이 없는 동안 쓰이지 않는 표면입니다.
- **배치 함수 하나** — `lib/workflowLayout.ts`. 간선에서 층을 계산하고(가장 긴 경로), `LOOP` 의 되돌이 간선은 DFS 로 끊어 층 계산에서만 뺍니다(간선 자체는 그려집니다). **좌표는 어디에도 저장되지 않습니다**(spec 0007 D-9) — 정의에도, `localStorage` 에도, 새 테이블에도.
- **표현 컴포넌트 하나** — `components/NodeKindIcon.tsx`. `Record<NodeKind, LucideIcon>` 이라 **api 에 노드 종류가 늘면 컴파일이 깨집니다**(상태 badge 셋과 같은 장치).
- **문서 테스트 하나** — `tests/scripts/test_web_design_deps.py`. R-10 을 기계로 바꿉니다.
- **문서** — `DESIGN.md` 1절(캔버스 행·토스트 행), 5절(새 화면), **6절 `NodeKind` 표 열셋**, 9절 한 줄.

## 왜 그렇게 했는가

- **의존을 들이기 전에 실측했습니다.** `@xyflow/react@12.12.0` 은 MIT, 설치 스크립트 없음, **런타임 네트워크 없음**(번들에 `fetch`·XHR 0건, CSS 에 `url(`·`http` 0건) — [../measurements/canvas-dependency-2026-10-23.md](../measurements/canvas-dependency-2026-10-23.md) 가 그 기록이고, plan 의 중단 조건("캔버스가 런타임 네트워크를 요구")에 걸리지 않음을 그 문서가 보입니다.
- **기본 테마를 쓰지 않습니다.** `dist/base.css` 만 import 하고 색·선폭은 `globals.css` 에서 `--xy-*` 를 2절 토큰으로 덮습니다. `base.css` 가 색을 `var(--xy-X, var(--xy-X-default))` 꼴로 읽기 때문에 가능합니다(28곳).
- **attribution 링크는 지우지 않았습니다.** DESIGN.md 1절이 그대로 두기로 적었습니다(끄는 것은 상류의 유료 구독 요청이라 사람의 결정입니다). 대신 `base.css` 가 anchor 에 직접 주는 `#999` 를 **토큰으로 덮었습니다** — 특이성이 높아 부모 선택자로는 덮이지 않았고, 리뷰에서 잡힌 것이 그것입니다.
- **중계는 한 칸도 늘지 않았습니다.** 서버에서 서버로 부르므로 `lib/relay.ts` 의 `ALLOWED_ROUTES` 는 GET 넷 그대로입니다(P5-3·P5-4 와 같은 선례).
- **읽기 전용입니다.** 캔버스의 끌기·연결·선택이 꺼져 있고 컴포넌트는 SDK 를 부르지 않습니다.

## 하네스 근거

- `web-unit` — 고정 그래프가 **노드·간선 수만큼** 렌더되고, 카드마다 종류 이름과 노드 id 가 함께 있고, 저장소 쓰기가 0건이며, **R-12 문장이 화면에 있습니다**. 배치 함수는 사슬·마름모·사이클·결정성·빈 그래프를 따로 판정합니다.
- `tests/scripts/test_web_design_deps.py` — ① `apps/web` 의 의존 중 DESIGN 1절에 없는 **시각 라이브러리가 0건**(R-10) ② 판정 함수 자체가 가짜 의존을 잡는지 ③ 캔버스 의존이 1절에 있고 **캐럿 없이 그 버전**인지 ④ `base.css` 만 import 하고 `style.css` 는 쓰지 않는지 ⑤ 캔버스 CSS 구간에 **hex 리터럴 0건**(D-1) ⑥ attribution anchor 색이 토큰인지.
- `web-build` — 번들에 CDN `<script>`·`@import url(https://…)` 가 없습니다(R-9). spec 27행의 금지 대상은 "외부 URL 을 **런타임에 받는** 구성" 이고 `<a href>` 는 해당하지 않습니다.
- 로컬 전량 **17/17 pass, 277,521 ms**(예산 900,000).

## 정한 것과 다른 점

- plan 의 P5-5 「만드는 것」에 **SDK 함수가 빠져 있었습니다**. api 에 경로가 있으므로 발명이 아니라 연결이고, 이 단위 안에서 했습니다(plan 개정 3).
- plan 의 「만드는 것」이 "노드 종류별 표현" 을 요구했는데 **`DESIGN.md` 6절에 `NodeKind` 표가 없었습니다**(6절은 상태 셋만 소유). 주 세션이 6절에 표를 더했고, 아이콘은 설치된 `lucide-react@1.44.0` 에 **실재함을 확인한 것만** 씁니다.
- `sonner` 가 1절에 적히지 않은 채 P0-3b 때 들어와 있었습니다 — **R-10 테스트가 그 누락을 드러냈고** 1절에 토스트 행을 더해 닫았습니다. 이 단위가 세운 테스트가 과거의 빠짐을 먼저 잡은 자리입니다.
- plan 의 판정 축약("번들에 외부 URL 0건")은 spec R-9 보다 넓습니다. spec 의 문구를 따랐고, 그래야 attribution 링크를 그대로 두는 1절 결정과 모순이 없습니다.

## 남긴 것

- **배치 함수는 결정적입니다** — 같은 그래프면 같은 좌표입니다. 그래도 화면의 R-12 문장("열 때마다 달라질 수 있습니다")은 그대로 둡니다: 그 문장은 무작위를 뜻하는 것이 아니라 **위치가 약속이 아니라는 뜻**이고, 좌표를 저장하지 않는다는 D-9 의 결과를 사용자에게 알리는 자리입니다.
- **간선 식별자가 응답에 없습니다**(spec C-7). 화면 안의 키를 `index` 로 만들어 쓰고 저장하지 않습니다 — P5-6 의 `violations[]` 가 간선을 지목해야 할 때 그 결핍이 다시 나옵니다.
- **버전을 골라 보는 화면이 없습니다.** `GET /workflows/{id}/versions/{version}` 은 api 에 있지만 SDK 함수도, 화면도 두지 않았습니다. 필요해지는 단위에서 그때 잇습니다.
