# P3-1 — Context Compiler v1 (PR #118)

모델 입력을 `ExecuteRunUseCase` 가 직접 조립하던 것을 **Compiler 한 곳**으로 옮겼습니다. `packages/context` 의 빈 껍데기에 첫 코드가 들어가고, AR-3(runtime → context 단방향)이 처음으로 막을 코드를 가집니다.

## 무엇이 생겼는가

- `packages/context` 의 `domain` — 소스·예산·`ContextReport`. `application` — `CompileContext` inbound 포트, `TokenCounter` outbound 포트, `CompileContextUseCase`. `adapters` — 문자 근사 토큰 계수기.
- `packages/runtime` 의 `ContextCompiler` outbound 포트와, `aether_context` 의 **inbound 포트 타입만** 보는 어댑터(AR-12). `execute_run` 이 모델을 부르기 전마다 그 포트를 지납니다.
- `AgentDefinition.context_budget_tokens`(D-5). `openapi.json` 은 기본값 있는 필드 하나가 더해지는 **추가 변경**이고 경로 수는 그대로입니다.
- `tests/arch/test_context_compiler_is_order_stable.py` — 조립 경로에 `set`·정렬 없는 매핑 순회를 금지하는 구조 테스트.

v1 은 `system`·`conversation`·`tools` 세 소스만 조립합니다. `knowledge`·`memory` 포트는 P3-3·P3-4 의 범위라 **선언하지 않았습니다** — 쓰지 않을 포트를 미리 두면 빈 구현이 생깁니다.

## 왜 그렇게 했는가

- **예산 초과 시 빼는 순서는 D-7** 이고, v1 에는 Memory·Knowledge 가 없으므로 실제로는 오래된 대화 → 도구 스키마의 `description` 입니다. `system` 과 **가장 최근 대화 한 쌍은 빼지 않습니다**.
- **토큰 근사는 올림입니다** — 과대 추정 방향이고 그 방향을 테스트가 고정합니다. 과소 추정은 모델 한계를 넘기지만 과대 추정은 조금 덜 넣는 것에서 끝납니다(D-6).
- **예산 기본값은 보수적인 고정값(8192)** 입니다. 모델별 한계를 알아내는 것은 이 Phase 의 범위 밖이고, 작게 시작해 늘리는 쪽이 조용한 품질 저하를 피합니다.
- **보고에 본문을 넣지 않습니다**(D-11) — 숫자와 종류만입니다. 감사 기록과 같은 이유입니다.

## 결정성 테스트의 한계를 실측으로 찾았습니다

plan 의 추가 확인은 "정렬을 제거하면 결정성 테스트가 깨지는지" 였는데, 구현이 정렬이 아니라 **`set`·순서 없는 `dict` 를 아예 쓰지 않는 방식**으로 결정성을 얻어 그 실험이 그대로는 성립하지 않았습니다. 그래서 `set` 을 주입해 봤더니 —

| 테스트 | 결과 |
| --- | --- |
| 결정성(100회 반복) | **통과** |
| D-7 순서 | 실패 |

같은 프로세스 안에서는 `hash()` 가 안정적이므로 **100회 반복으로는 해시 시드 의존 비결정성을 잡지 못합니다.** 반복 횟수를 늘려도 같습니다. 그래서 구조 테스트를 더했습니다 — 주입하면 실제로 잡습니다(`compile_context.py:91 set()`).

이 사실은 P3-2b 에서 다시 확인됐습니다(`test_list_documents_is_deterministic_across_repeats` 가 같은 부류를 잡지 못함). 반복 횟수는 이 부류의 결함에 대한 검출력이 아닙니다.

## 정한 것과 다른 점

- H-1(`.importlinter` 예외 한 줄)은 **필요하지 않았습니다**. spec D-14 가 "필요 여부를 미리 단정하지 않는다" 로 두었고, 실측 결과 조립이 `aether_context.adapters` 를 보지 않아 예외가 필요 없었습니다.
- 실행자가 세션 한도로 전체 verify 직전에 중단됐습니다. 그 뒤(판정 명령 전부, 결정성 주입 실험, 구조 테스트 추가, verify)는 주 세션이 수행했습니다.
